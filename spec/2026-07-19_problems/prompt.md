ปัญหาที่เจอตอนนี้

ทุกหน้าที่ใช้ศัพท์ไทยแทนได้อยากให้ใช้ศัพท์ไทย บางหน้า customer อยากได้เป็น ลูกค้า เหมือนกัน ไทยคำอังกฤษคำ แปลกๆ ช่วยเช็คหน่อย

หน้า http://localhost:5173/inventory 
อยากรู้ว่า หมวดหมู่ดึงมากจากตรงไหน ผมไม่อยาก hardcode ถ้าไม่มีช่วยสร้าง module api และหน้าบ้านให้ด้วย

หน้า http://localhost:5173/sales/invoices
- ตอนเปิด modal new invoice ตรง customer กับ product ยังค้นหา และ เหมือน pagination ใช้ยังไม่ได้ และช่วย เพิ่ม seed data customer และ product เป็น อย่างละ 20 ให้หน่อย
- e2e test ให้ด้วย test ครบ flow สร้างลบแก้ไขได้ ประวัติขึ้นมั้ย

หน้า http://localhost:5173/jobs
- ตัว ลูกค้า ก็อยากให้เป็นเหมือนหน้า sales invoice ถ้าแก้่ไขสำเร็จแล้ว 
- และอีกปัญหาคือตอนเลือกลูกค้า ดันยิง api รั่วๆ ไม่รู้เกิดจากอะไร 
- ยังไม่เจออะไรเพิ่มเลยไม่รู้จะทำไงต่อ
- e2e test ให้ด้วย สร้างงานได้จริงมั้ย ลบแก้ไขได้จริงมั้ย ประวัติขึ้นมั้ย

และอยากให้เพิ่่มหน้าจัดการผู้ใช้งานด้วยครับ
